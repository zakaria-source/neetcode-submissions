# NeetCode — Java Interview Practice

A structured collection of data-structure and algorithm exercises solved primarily in **Java** for technical interview preparation.

> Solutions are synced automatically from NeetCode.io.

## Goal

This repository is used to practice reusable problem-solving patterns rather than simply accumulate accepted submissions.

For each topic, the focus is on:

- Recognizing the underlying pattern quickly
- Writing clear and idiomatic Java
- Understanding time and space complexity
- Handling edge cases deliberately
- Revisiting problems that required hints

## Review Checklist

When revisiting a solution, I check:

1. Can I explain the brute-force approach first?
2. What observation enables the optimized solution?
3. Which data structure or algorithmic pattern is being used?
4. What are the time and space complexities?
5. Which edge cases could break the implementation?
6. Can I reproduce the solution without looking at the previous code?

## Java Focus

The Java solutions emphasize:

- Appropriate use of collections such as `HashMap`, `HashSet`, `ArrayDeque` and `PriorityQueue`
- Clear method boundaries and naming
- Avoiding unnecessary allocations
- Correct handling of nulls, indexes and integer boundaries
- Interview-friendly implementations that are easy to explain
